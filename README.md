# Studio SP_ACE website

Portfolio site for Studio SP_ACE, an interior design studio in Bangalore.
Built with Next.js 16 (App Router), Tailwind CSS v4, GSAP and Lenis; project
media is hosted on Cloudinary, and new projects and press mentions can be added
by the client through Sanity at `/studio`.

**New to the codebase? Read [ARCHITECTURE.md](ARCHITECTURE.md)** for the folder
structure, data flow (project order, gallery order, covers), animation
conventions, and deployment.

## Run it

Requires Node 22.12+.

```bash
npm install
cp .env.example .env.local   # fill in real values; see ARCHITECTURE.md section 8
npm run dev                  # development, http://localhost:3000
npm run build && npm start   # production build (test against this)
npm run lint
```

## Deploy

Standard Node server (`npm run build` then `npm start`), no Vercel-only
features. Set the environment variables from `.env.example` on the host
**before building**. The full list and hosting notes are in ARCHITECTURE.md
section 8.
